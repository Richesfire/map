# 成品（圈定地块）

这里只放**手工圈定的地块成品**：城池、村庄、关隘、渡口、遗迹之类。

**不在这里放的东西**：

- 植被零件 → `assets/零件/`（.blend 源）+ `assets/零件_导出/`（.glb 与预览）
- 地形白模 / 纹理 → 各 `assets/零件/<地形>/`
- 程序化生成的普通地块 → 不进仓库，运行时由代码算

---

## 一个成品 = 一个地块

一个成品对应**一个 1 km² 的地块**（与代码里的 `DesignatedTile` 一一对应）。

### 目录结构

```
成品/
└─ <地块编号>/
   ├─ <地块编号>.blend        源文件
   ├─ <地块编号>.glb          导出（游戏读这个）
   ├─ 纹理_<地块编号>.png     地表纹理（可多张：_a _b _c）
   ├─ 布局.md                文字说明：这里是什么、发生了什么
   └─ _预览.png              一张渲染图
```

### 命名

- 一块地一个编号，**全局唯一**，比如 `qin_xiangyang_01`
- 编号只用小写字母、数字、下划线（**不要用中文**——这个目录要进 git，可能跨平台）
- 中文名写在 `布局.md` 里

### 尺寸约定

| 项 | 约定 |
|---|---|
| 地块范围 | 1000 × 1000 m，原点在地块中心，地面 z = 0 |
| 单位 | 1 单位 = 1 米 |
| 建筑高度 | 按真实尺度，不要为了好看放大 |
| 出口 | 四面边缘各留 50 m 空地，方便和相邻地块接缝 |
| 碰撞 | 只给可站立面做碰撞，装饰（屋檐、旗子）不加 |
| 面数 | 单个成品建议 ≤ 5 万三角面 |

### 和代码的接线

地块中心经纬度与编号的对应关系写在 `data/地形表.xlsx`（后续会加一页「圈定地块」），
导出后进入 `godot/data/terrain_types.json`，代码据此在对应位置放这一块。
