# 地图零件 · 源文件说明

按总纲「零件」里的 **植被** 一类做的第一批。
（地形白模、地形纹理不是模型，它们在代码和贴图那一侧，不在这里。）

## 二、改模型时别破坏的约定

| 项 | 约定 | 为什么 |
|---|---|---|
| **单位** | 1 Blender 单位 = 1 米 | 地块是 1000 单位 = 1km，植被按真实尺寸放才不违和 |
| **原点** | 模型**底面中心**，Z = 0 | 地图按地表高度实例化，原点在脚底才不会浮空或陷地 |
| **朝向** | Z 朝上；导出时勾 +Y Up | glTF 标准，Godot 那边 1:1 对应 |
| **材质** | 每个零件自带材质 | 导出 glb 一起带走，Godot 直接用 |
| **双面** | 叶片类关掉 `Backface Culling` | 单片草叶从背面看不能消失 |
| **不要有多余物体** | 一个 .blend 只放一个物体 | 导出时按“选中物体”走，多一个就会连相机/灯光一起导出 |

## 三、面数预算

现在是 28 / 54 / 18 面，非常轻。**建议单件控制在 300 面以内**。

原因：一个 1km² 地块最多会撒几千个实例（草丛最密），一个 3×3 区域就是几万个。
超了必须先做 LOD（远处换低模），否则帧率会崩。

## 四、命名与扩展 —— 对齐总纲的新结构

你在总纲里新加的结构是**按地貌分组的三件套**：

```
平原 → 白模地形1、地形纹理1、植被1（树1、树2、石头1、石头2…）
森林 → 白模地形2、地形纹理2、植被2（树3、树4、石头3、石头4…）
沙漠 → 白模地形3、地形纹理3、植被3（树5、树6、石头5、石头6…）
```

**零件编号是全局递增的**（树1→树6 跨地貌连续），所以文件名直接按编号走：

```
树_01.blend  树_02.blend  树_03.blend …
石头_01.blend 石头_02.blend …
低矮植被_01.blend …
```

**地形归属不改文件名，记在清单里。**

完整的地形分类（15 类，按世界地形粗补）在上一级目录的
**`_地形分类表.md`**，机器可读版在：

`qinmo-tilegen/godot/data/terrain_types.json`

那里面写清了每一类地形配哪几套白模/纹理/植被，零件编号也按那张表走。

现有三个占位件的归属：

| 文件 | 归到 | 编号 |
|---|---|---|
| `树_01.blend` | 森林（针叶） | 树_01 |
| `石头_01.blend` | 平原（通用石） | 石头_01 |
| `低矮植被_01.blend` | 平原（草叶簇） | 草_01 |

## 五、导出设置（Blender）

菜单 `File → Export → glTF 2.0 (.glb)`：

| 选项 | 值 |
|---|---|
| Format | **glTF Binary (.glb)** |
| Include | **Selected Objects**（只导选中物体） |
| Transform → +Y Up | ✅ 勾上 |
| Data → Apply Modifiers | ✅ 勾上 |
| Geometry → Normals | ✅ |
| Geometry → UVs | 有贴图才需要 |

我自己是用 `blender/build_map_parts.py` 里的参数批量导的，参数和上面一致。

## 六、在 Godot 里怎么用

1. 把 `.glb` 拷进工程：`godot/assets/parts/`
2. 打开 `godot/scripts/map/map_world.gd`，找到 `_build_materials()` 里的：

```gdscript
_prop_meshes = {
    "tree": PropMeshes.tree(),      # ← 换成 load("res://assets/parts/树_01.glb")
    "rock": PropMeshes.rock(),
    "low_veg": PropMeshes.low_veg(),
}
```

3. **同时把 `_prop_material` 置 null**。占位几何是靠「顶点色当 albedo」上色的，
   真模型自带材质，如果还套着那个共享材质，会被刷成白模。
   代码里已经做了判断：`prop_material` 为 null 时不覆盖材质。

## 七、还没做的（和总纲新结构对不上的地方）

| 缺什么 | 说明 |
|---|---|
| **地貌分组** | 现在地图还是「一套地形 + 一套纹理 + 三种零件」，没有按 平原/森林/沙漠 切换。这是总纲新增结构带来的最大改动 |
| **白模地形分类** | 现在所有地块用同一个高度场规则。新结构要求「平原白模」「森林白模」「沙漠白模」是**不同形状**的地形 |
| **地形纹理分组** | 现在只有 草 / 泥土 两张，要按地貌扩成多套 |
| **颜色→零件的调色板图片** | 总纲要的「通过颜色区分的图片确定零件」还没做 |
| **植被零件只做了 3 个** | 新结构里每个地貌至少要 2 树 + 2 石头，三个地貌就是 12 个植被件起 |
