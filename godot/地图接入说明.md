# IAS × 地图模块 · 接入说明

这份工程 = 你的 `IASv1.0`（动作/战斗/骑乘一行未改） + 地图模块。

## 怎么跑

用 Godot 4.7 打开本目录 → F5。

启动只生成**脚下 1 块**地块（约 **0.8 秒**），周围 3×3 由**流式加载**边跑边补，
玩家走到哪，附近的地块就建在哪，跑远的自动释放（常驻 9~15 块，上限 15）。

| 键 | 作用 |
|---|---|
| WASD / 空格 / F / ~ | 和原来完全一样（走、跳、上马、观察镜头） |
| **Backspace** | 灵魂状态（冻结玩家，自由飞行）/ 再按回到身体 |
| **M** | 打开 / 关闭世界地图（地球仪）。**不会改变右上角小地图** |
| **鼠标左键拖拽**（地图里） | 转**球体**。往右拖 = 球面往右走；上下拖 = 球面往下走（限 ±75°） |
| **滚轮**（地图里） | 缩放地球仪（0.6× ~ 2.6×） |
| **Esc** | 关了地图就回身体；地图开着就先关地图 |

世界地图打开时会**冻结玩家并释放鼠标**，拖动地球仪不会带动人物视角。

## 接的时候踩的坑（都修了，记下来免得再踩）

| 症状 | 原因 |
|---|---|
| 场景一片漆黑 | 我重写 `main.tscn` 时把 `DirectionalLight3D` 弄丢了；现在 `world_root` 里没有就自己建 |
| 玩家/相机整体歪掉、贴脸 | 地图的区域坐标系加了旋转，但玩家、相机、灯光都是世界 Y 朝上。地形顶点本来就已算成 Y 朝上的局部坐标，**那层旋转是多余的**，已改成单位变换 |
| 人物站在土里 | `reparent` 前先按原路径查节点，搬完路径失效 → 拿到 null。改成先查后搬 |
| `HeightMapShape3D` 碰撞对不上 | 行序/朝向不对（物理 8.39 vs 解析 25.34）。退回三角网，校验差 0.00 / 0.23 / 0.08 m |
| 地面被雾糊成一片 | 你的 Environment 是按 170m 场景配的（`fog_density=0.012`），1km 尺度要用 0.00022 |
| 地球仪 shader 编译失败 | Godot 的 `fragment` 里**不允许 return**，改成 if/else 两个分支赋值 |
| **Backspace 没反应** | 热键写在 `_unhandled_input` 里，被 `player.gd` 的输入处理抢先吃掉了 → 改走 `_input` 并 `set_input_as_handled()` |
| **地球仪拖不动** | 父节点是 CanvasLayer，`set_anchors_preset(FULL_RECT)` 没算出矩形，Control 是 0×0，收不到鼠标事件 → 改成锚点全 0 + 自己设 position/size |
| **.tscn 报 `Expected '['`** | PowerShell `Set-Content -Encoding UTF8` 写入了 BOM，Godot 的 tscn 解析器不认 → 已全部剥掉 |
| **地球仪拖不动（第二次）** | 用的是 `_gui_input`，它依赖 GUI 命中测试（CanvasLayer 层级、悬停、鼠标捕获都会影响），这套场景里收不到。改成 `_input` 全局吃事件——地球仪本来就是全屏模态 |
| `look_at` 报 "Node not inside tree" | 相机还没 add_child 就 look_at。改成直接给位置（默认朝 -Z 正好对着原点） |
| `mat.specular` 不存在 | `StandardMaterial3D` 里叫 `metallic_specular` |
| 地球朝向反了 | 球体应用 `R_y(spin)`，要把方向转到镜头前方得 `spin = -atan2(p.x, p.z)`，不是 `-经度` |

## 已知限制

1. **地图还是程序化占位植被**（圆锥树 / 球石头 / 草锥）。46 个 Blender 零件已经做好了，
   但还没接进来——见 `scripts/map/map_world.gd` 的 `_prop_meshes`。
2. **没有海**。5.1 亿格全是陆地。
3. **碰撞是全量三角网**：9 块约 1.4 秒、约 10MB。铺到 10×10 就要改成按需生成。
4. **世界是局部切平面**，不是真球面渲染。走 1000km 不会感觉到地球曲率（也不该感觉到）。
5. 小地图底图约 0.3 秒生成一次，跑出 30% 半径外会重新生成（会有一帧卡顿）。
6. 大地图的世界贴图是 512×256（含真实海陆），一次生成约 1.6 秒，之后拖动是 GPU 实时。
7. **撒点密度场是粗网格插值**（32×32/块）：密度本身是百米级低频，按 5~7m 逐点查是 21 倍过采样。
   这一项把撒点从 500ms 压到 226ms。
8. **单块 400ms 已经摊到 19 帧里**（两段式）：粗版 33×33 立刻出（10ms），
   之后精细高度采样 / 视觉网格 / 碰撞 / 密度场 / 撒点各自分帧推进，**单帧峰值 19ms**。
   碰撞**必须和视觉网格同精度**：为了省时间降到半精度（129→65）会让山丘的碰撞面比看到的低，
   骑马冲上去就沉进山体。已改回全精度，校验误差 0.04~0.23m。代价是碰撞那一步回到约 60ms。
9. **远景壳**：3×3 只有 3km，雾的能见度却是 4~5km，地平线会露白。用一张 18km×18km、
   97×97 顶点的低精度网补上（不撒点、不碰撞），高度走同一个 `height_at()`，整张下压 3m
   让近处高精度瓦片盖住它。只在玩家移动超过 1.2km 时重建一次（约 120ms）。
   整张网下压 **1.5m**（原来是 3m），让近处瓦片盖住它；代价是交界有约 1.5m 的台阶，靠雾淡化。
   **玩家脚下那一块永远不释放**，否则人物会踩到低 1.5m 的远景壳上，看起来像"地下还有一层地"。
10. **掉出地表兜底**：每帧比对解析地面高度，人物低于地面 **0.8m** 以上就拉回地表。
    阈值必须小于远景壳的下压量（1.5m），否则人物卡在壳下会看到"整片天空是黑的"
    （黑的是远景壳的背面，不是天空）。
11. **失焦释放鼠标**：Alt+Tab / 截图 / 点到别的窗口时自动放开鼠标捕获，回来再抓回。
   （传送、地块重建、掉穿都会触发）。日志会打 `人物掉出地表，已拉回`。

## 协作约定（给 AI / 协作者）

**需要跑测试、截预览图、或改完要验证时，直接让策划关掉 Godot 引擎，不要试图在引擎开着的情况下操作。**

原因：

- Godot 编辑器会锁住 `.godot` 导入缓存和工程目录，`--import` / 截图 / 删除文件都会失败（实测报过「正由另一进程使用」）
- 引擎里跑的还是**旧代码**，改了文件也不生效，容易误判"没修好"
- 编辑器进程占 CPU，测量构建耗时不准

标准流程：

1. AI 说「请关掉 Godot」
2. 策划关闭引擎（不是最小化，要退出）
3. AI 跑测试 / 截图 / 改文件
4. AI 说「可以开了」，并给出本次构建标记

**判断跑的是不是最新代码**：看游戏窗口左上角那行 `BUILD_TAG`，或在控制台找 `[World] BUILD_TAG = ...`。
