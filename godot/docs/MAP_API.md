# 地图模块 · 接口契约（球面版）

> 这份文档是给**其他模块（以及写它们的 AI）**看的。
> 你不需要读地图模块的实现，只要照这份契约调用就行。

---

## 0. 一句话

地图模块只回答三件事：

1. **这个方向长什么样** —— 高度、坡度
2. **这个方向是自由地块还是选定地块** —— 随机生成 or 城池/遗迹
3. **这个方向属于哪个格子** —— 全球地址

它**不生产**内容、美术、玩法、势力、兵种、经济。

---

## 1. 模块边界

```
   其他模块 / 你的游戏主场景
            │
            │  只允许依赖 MapWorld + MapConfig + DesignatedTile + DesignatedTileRegistry
            │  + GeoSphere（查地址、算距离、经纬度换算）
            ▼
   ┌──────────────────────────────────────┐
   │  map_world.gd      MapWorld  ← 唯一入口│
   │  ├─ build()          铺地块            │
   │  ├─ 查询 API         高度/坡度/地块    │
   │  ├─ 信号              designated_tile_placed │
   │  └─ 标注              annotations[]    │
   ├──────────────────────────────────────┤
   │  designated_tile_registry.gd  选定地块表│◄── 由你的内容模块注入
   │  minimap.gd            小地图           │
   │  map_annotation.gd     地图标注（≠地块）│
   │  terrain_noise.gd      纯数学（无节点）│
   │  terrain_tile.gd       单块网格 + 撒点 │
   │  geo_sphere.gd         立方体球地址系统│
   │  terrain_splat.gdshader 地表混色       │
   └──────────────────────────────────────┘
```

**依赖方向是单向的**：`scripts/map/` 里没有任何一行代码引用别的模块。
`scripts/demo/` 是演示，`scripts/tools/` 是开发探针，都不属于模块，可以整个删掉。

## 2. 坐标系 —— 最容易踩的坑

### 2.1 三种表示

| 名字 | 类型 | 说明 |
|---|---|---|
| **方向** | 单位 `Vector3` | 球面上的一点。**地图的主要参数都是它** |
| **格子** | `Vector3i(面号 0..5, x 0..9215, y 0..9215)` | 全球唯一地址。可当字典键、可直接存盘 |
| **渲染坐标** | `Vector3`（米） | 只在一个已加载区域内有效，**不要存档** |

### 2.2 为什么不是经纬度网格

等距圆柱投影下「一格 = 1km²」在赤道成立，但：

| 纬度 | 一格实际面积 | 地方 |
|---|---|---|
| 0° | 1.00 km² | 赤道 |
| 23° | 0.92 | 番禺 |
| **35°** | **0.82** | **咸阳** |
| 48° | 0.67 | 匈奴 |
| 60° | 0.50 | 北欧 |
| 70° | 0.34 | 北极圈 |

**南北向和东西向的行军距离会严重不一致。** 所以换成了立方体球。

### 2.3 立方体球（cube-sphere）

把地球投到立方体的 6 个面上，每面切成 `9216 × 9216` 格：

| | |
|---|---|
| 每面格数 | 9216 = 2¹⁰ × 9 |
| 全球格数 | 6 × 9216² = **5.096 亿** |
| 平均面积 | 全球表面积 5.101 亿 km² ÷ 5.096 亿格 = **1.001 km²** |
| 面积区间 | **0.83 ~ 1.18 km²**（面中心最大、面角最小），**与纬度无关** |

查询某一格的真实面积：`GeoSphere.tile_area_m2(tile)`。

### ⚠ 两个网格不是一回事（重要）

必须区分「**格子 cell**」（地址）和「**地块 tile**」（你在地图上看到的那块地）：

| | cell（地址） | tile（实际地形） |
|---|---|---|
| 是什么 | `Vector3i(面, x, y)`，整数地址 | 切平面上的 1000×1000m 方格 |
| 尺寸 | 东西 768~1086m，南北 768~1086m（**面内变化**） | 恒定 1000×1000m |
| 面积 | **0.83~1.18 km²** | **1.000 km² ±0.01%** |
| 长宽比 | **1 : 1.414 最差**（面边中点）；面中心 1:1 | 永远 1:1 |

实测（FACE_RES=9216）：

| 位置 | 东西 | 南北 | 长宽比 | 面积 |
|---|---|---|---|---|
| 面中心 | 1085.9 m | 1085.9 m | 1.000 | 1.179 km² |
| 面角 | 1023.7 m | 1023.7 m | 1.000 | 0.908 km² |
| **面边中点** | **1085.9 m** | **768.0 m** | **1.414** | **0.834 km²** |

**结论：地形永远不拉伸。** 因为地形是按 tile（切平面方格）程序化生成的，
跟 cell 的形状无关。cell 只是地址，一块 1km 的 tile 可能压在 1~4 个 cell 上。

**什么时候才会拉伸**：如果哪天把「一个 cell 一块地形」直接当几何体渲染（比如太空视角看真球），
那时 1000×1000 的方形地形资产贴到 1.414 长宽比的 cell 上就会被压扁 29%。
真要做球面渲染，必须按 cell 的四边形重新生成网格，而不是拉伸方图。

> **为什么不是严格 1.000 km²**：立方体球上不存在既等面积又保持方格形状的映射。
> 要绝对等面积得用 COBE 四边形化映射，格子会变成不等边四边形，
> 对「东南西北各走一格」的格子玩法不友好，所以选了「近正方形 + ±18% 面积」。
> 换算映射只在一个函数里（`GeoSphere._warp/_unwarp`），想换随时能换。

### 2.4 距离 —— 唯一正确算法

```gdscript
var d := GeoSphere.distance_m(dir_a, dir_b)   # 大圆距离，米
```

> **禁止**拿格子索引差值算距离。格子在不同位置的真实边长不同，
> 而且跨立方体面时索引根本不连续。

> ⚠️ 内部踩过的坑：不能用 `acos(a·b)` 算小距离。
> 两点相距 1km 时 `a·b = 1 - 1.2×10⁻⁸`，而 `Vector3` 是 32 位浮点
> （1.0 附近 ULP 约 6×10⁻⁸），点积会被舍成 `1.0`，`acos` 恒为 0。
> 现在用弦长 `2·asin(|a−b|/2)`，1km 实测返回 999.96 m。

### 2.5 经纬度换算

```gdscript
var dir := GeoSphere.lonlat_to_dir(108.71, 34.33)   # 咸阳
var ll  := GeoSphere.dir_to_lonlat(dir)             # Vector2(经度, 纬度)
var t   := GeoSphere.dir_to_tile(dir)               # Vector3i(3, 6523, 8273)
var d   := GeoSphere.tile_to_dir(t)                 # 格子中心方向
```

### 2.6 渲染坐标（局部空间）

地形节点全部挂在一个「区域坐标系」下：`x = 东`、`y = 天`、`z = 南`。

- 它只做**旋转**，不做平移
- **绝对不要**把节点摆到球面真实位置上（6.37×10⁶ 米），`Vector3` 在那个量级精度只剩 0.5 米，地形会抖
- 球面位置只在数学层参与计算，节点坐标永远是「切平面上的米」，量级几公里

```gdscript
# 方向 -> 可以塞进 Vector3 的局部坐标（自动查地表高度）
node.position = map.render_position(dir, 0.0)

# 相机 / 灯光挂到区域坐标系下，这样 Y 才真的是"上"
map.frame_node().add_child(my_camera)
```

## 3. 对外 API

### 3.1 装配

```gdscript
var map := MapWorld.new()
map.setup(MapConfig.new(), 209, DesignatedTileRegistry.new())  # config, seed, 选定地块表（默认空）
add_child(map)
map.build(GeoSphere.lonlat_to_dir(108.71, 34.33), 3, 3)  # 中心方向, 块数x, 块数z
```

| 方法 | 说明 |
|---|---|
| `setup(cfg, seed, registry)` | 建噪声、解析地标高度、建材质。**必须在 `build()` 之前** |
| `build(center_dir, tx, tz, do_scatter)` | 以某个方向为中心铺 `tx × tz` 个地块。可重复调用换区域 |
| `frame_node()` | 区域坐标系节点，相机/灯光挂这里 |
| `set_white_model(on)` | 只看白膜（调试） |

### 3.2 查询（参数都是方向）

| 方法 | 返回 | 说明 |
|---|---|---|
| `get_height_dir(dir)` | `float` 米 | 真实地表高度，**含选定地块平台** |
| `get_height_lonlat(lon, lat)` | `float` 米 | 同上，直接给经纬度 |
| `get_slope_deg_dir(dir)` | `float` 度 | 坡度。采样 4 次，别每帧每单位调用 |
| `dir_to_tile(dir)` | `Vector3i` | 全球格子地址 |
| `designated_tile_at_dir(dir)` | `DesignatedTile` / `null` | 这一格是不是你手工圈定的 |
| `render_position(dir, dy)` | `Vector3` | 局部渲染坐标（自动查高度） |
| `dir_to_render(dir, h)` | `Vector3` | 同上，可指定高度 |

### 3.3 信号

| 信号 | 参数 | 什么时候发 |
|---|---|---|
| `region_built` | `(center_dir, tx, tz)` | 一片地块铺完 |
| `designated_tile_placed` | `(tile, local_position)` | 落在本区域内的选定地块。**你的内容模块接这里** |

## 4. 两个**完全不同**的概念，别搞混

| | 选定地块 `DesignatedTile` | 标注 `MapAnnotation` |
|---|---|---|
| 是什么 | **你手工圈定的格子**，地图要特殊处理 | 地图上的一个具名点，只是名字 |
| 影响生成吗 | 会（可压平、可禁撒点） | **完全不会** |
| 默认有多少 | **0 个**（全世界都是未选定地块） | 0 个，随便加 |
| 典型用途 | "这格我要摆城，别随机长树" | 小地图上标"咸阳""罗马" |

> 「咸阳」这种**不是**选定地块，是标注。你现在一个选定地块都没圈，所以全世界都是程序化生成——这是正确的默认状态。

### 4.1 选定地块

```gdscript
var reg := DesignatedTileRegistry.new()      # 默认空表，不圈就是空

var dt := DesignatedTile.new()
dt.id = "t_0001"
dt.note = "这一格留给主城"
dt.tile = GeoSphere.dir_to_tile(GeoSphere.lonlat_to_dir(108.71, 34.33))
dt.size_tiles = 1            # 占几格×几格（同一立方体面内）
dt.clear_scatter = true      # 这一格不撒树/石头/草丛（默认）
dt.flatten_amount = 0.0      # 0 = 保留程序化地形（默认）；1 = 完全压平
dt.flatten_radius_m = 500.0  # 压平半径，仅 flatten_amount > 0 时生效
dt.flatten_height_m = -1.0   # 负数 = 自动取该点地形高度
dt.payload = my_data
reg.add(dt)
```

地图对它只有三条义务：

1. **默认不动地形**（`flatten_amount = 0`），只有你调大才压平
2. 这一格里**不撒**零件
3. 铺完地块后发 `designated_tile_placed`，你把模型挂到 `local_position`

### 4.2 标注

```gdscript
map.add_annotation(MapAnnotation.from_lonlat("xianyang", "咸阳", 108.71, 34.33))
```

只在画小地图时被读，不碰地形。

## 5. 小地图

```gdscript
var mm := MapMinimap.new()
add_child(mm)
mm.setup(map, camera)      # 自动读 map.annotations 和 map.registry
```

两种模式，`M` 键或 `mm.toggle_mode()` 切换：

| 模式 | 内容 |
|---|---|
| **LOCAL**（默认） | 以当前区域为中心约 2.6km，画地形起伏、坡度、选定地块方框、标注名、玩家位置与朝向 |
| **GLOBE** | 整个地球，带 30° 经纬网格、标注点、玩家所在半球 |

底图**不是在 CPU 上每帧重画**：切模式或换区域时生成一次 192×192 纹理
（局部约 37k 次高度采样、全球约 29k 次），之后只重绘覆盖层。

对外可调的：

| 属性 / 方法 | 说明 |
|---|---|
| `local_span_m` | 局部模式覆盖多少米（默认 2600） |
| `toggle_mode()` | 切换局部 / 全球 |
| `refresh()` | 底图重画（换区域、改 seed 后调用） |
| `globe_center` | 全球模式看向哪个方向，默认取区域中心 |

中文标注名：Godot 默认字体没有中文字形，`MapMinimap` 会自动尝试加载
`C:/Windows/Fonts/msyh.ttc` 等系统中文字体，找不到才退回默认字体。

## 7. 性能参考（Godot 4.7.2 实测）

单个 1km² 地块（`mesh_res = 129`，撒点全开）：

| 项 | 数量 |
|---|---|
| 网格顶点 / 三角形 | 16384 / 32768 |
| 树木实例 | 约 100~900 |
| 石头实例 | 约 0~80 |
| 低矮植被实例 | 约 500~3000 |
| 生成耗时 | 约 500 ms |

**3×3 共 9 块、全开撒点：实测 5.5~7.8 秒**（控制台打印，视负载）。
卡的话按顺序调：`MapConfig.low_veg_step_m` → `tree_step_m` → `mesh_res`。

`get_height_dir()` 一次约 15 次三维噪声采样。寻路要密集采样的话跟我说，
我给地块加一层可缓存的高度栅格。

## 8. 还没定的

| 问题 | 现状 | 影响谁 |
|---|---|---|
| **海洋 / 水域** | 现在**全是陆地**，没有海 | 港口、航路、渔猎 |
| **地块归属** | 哪个地块归哪个势力，地图不管 | 势力/外交模块 |

| **立方体棱上的选定地块** | 只在同一个面内占格子，压着棱的不会自动跨面 | 内容模块（放大 `size_tiles` 手工处理） |

> 面积均匀性（0.83~1.18 km²）已经定案，不改了。要绝对等面积再找我。

## 10. 验证状态

已在 **Godot 4.7.2** 实跑通过：导入无错、脚本无编译错误、无头与带窗口模式都试过。

改成球面版的过程中修掉的坑（记下来免得复现）：

| 症状 | 原因 |
|---|---|
| 地标把整片地压平 | `acos(a·b)` 算小距离恒返回 0 → 改弦长公式 |
| 地表全变土色 | 球面下「上」不再是世界 Y，着色器还按世界 Y 算坡度 → 改用区域局部法线 |
| 地形整片发黑 | 局部坐标 z 取负之后三角形绕序反了 → 翻转绕序 |
| 画面长期发灰 | 往 `NORMAL` 写世界空间法线（那是视空间槽位）→ 删掉，用引擎自带法线 |
| 顶点色发白 | 顶点色是线性空间，写 sRGB 要过 `srgb_to_linear()` |
| 全屏白雾 | `fog_density` 量级搞错 |

跨立方体面连续性：地形用三维噪声按方向采样，`preview/check_cube_sphere.py`
数值验证过往返误差 3.6×10⁻¹⁶、跨面噪声差 0。

再报错就把红色报错贴出来。
