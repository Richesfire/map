# 地图渲染设计 V1（2026-11-20）

## 0. 为什么重写这份设计

过去几天的修改是"补丁式"的：分类纯色 → 分类边界矢量 → 高程配色 → 运行时等高线，每换一次都要推翻上一层，还留下了三个坐标变换、两层贴图、若干缓存。问题不在某个函数，而在**没有分层**。

这份文档定三件事：**数据只算一次、渲染只分三层、坐标只有一个函数**。

---

## 1. 数据层：一次离线算完，运行时只读

所有地形相关的东西都从**同一份高程数据**（`dem2k.bin`，16384×8192，uint16）离线生成，存进 `ias-core/data/`：

| 文件 | 内容 | 分辨率 | 大小（估） |
|---|---|---|---|
| `map_color.bin` | 高程配色后的 RGB（或调色板索引） | 8192×4096 | 32–96 MB |
| `map_shade.bin` | Hillshade 灰度（西北向、45°、0–255） | 8192×4096 | 32 MB |
| `map_contour_500.bin` | 500 m 等高线折线（平滑、简化） | 矢量 | 3–6 MB |
| `map_contour_250.bin` | 250 m 等高线折线（仅山地用） | 矢量 | 6–12 MB |
| `hydro.json` | 河流/湖泊折线 | 矢量 | 已有 |

生成工具：`ias/tools/build_map_layers.py`，一条命令：

```
python ias/tools/build_map_layers.py        # 颜色 + 阴影 + 两套等高线
```

**规则**：分类（31 类地貌）从此只用于 3D 世界和小地图，不再参与 2D 地图渲染。

### 等高线提取（已验证可用的算法）

1. 对高程做 3×3 均值平滑（消除 2.4 km 数据的台阶）；
2. Marching Squares 按阈值（500 / 250 m）提取线段；
3. 端点吸附合并成折线，**三岔口取转角最小者继续**（不横穿、不交叉）；
4. Douglas-Peucker 简化（0.5 格）；
5. Chaikin 平滑 2 次；
6. 按 bbox 存成紧凑二进制（int16 经纬度）。

## 2. 渲染层：三层，各管各的

```
map_root (Control)
 ├── terrain_quad      ← 一张贴图（color × shade），一个 draw 调用
 ├── vector_layer      ← 等高线 / 海岸线 / 河流 / 道路（折线，LOD 过滤）
 ├── marker_layer      ← 聚落图标 + 选中光圈（屏幕尺寸固定）
 └── ui_layer (CanvasLayer) ← 罗盘 / 信息面板 / 图例 / 返回（不随缩放变）
```

### 2.1 地形层

- 一个 `TextureRect`（或 `draw_texture_rect`），贴 `map_color` + `map_shade` 两张 8192 纹理；
- 简单 shader：`final = color * (0.65 + 0.35 * shade) * paper_tint`；
- 放大时就是这张图被拉伸——**没有第二层贴图、没有分类边界、没有运行时烘焙**；
- 8192 贴图在 500 倍下 1 texel = 4.9 km，会糊；但颜色是连续的，糊成渐变，不像色块那样刺眼。

### 2.2 矢量层

- 折线数据按 bbox 分桶（10°），只取视野内的；
- 按 LOD 过滤：低倍只画主干（500 m 线 + 大河流），高倍画 250 m 线；
- 线宽用屏幕像素（1.0–1.4 px），不随缩放变粗；
- 海岸线单独画（颜色略深）。

### 2.3 标记层

- 聚落图标用**一张纹理图集**（城/镇/邑/关/废墟各一格），一次 `draw_texture_rect_region` 画完；
- 图标尺寸固定屏幕像素（8–28 px），随缩放只改变显示数量；
- 选中时画一个金色光圈（`draw_arc`）。

## 3. 坐标：只保留一个函数

```gdscript
## 唯一的经纬度 → 屏幕映射。所有层都必须用它。
func map_point(lon: float, lat: float) -> Vector2:
    return map_origin + Vector2((lon + 180.0) * map_ppd, (LAT_LIMIT - lat) * map_ppy)
```

`map_origin / map_ppd / map_ppy` 在 `_draw_map` 开头算一次，赋值给成员；其余地方只读。

历史上出过的三个 bug（矢量偏到左上、等高线错位、线断）全是"又写了一个变换"造成的。

## 4. LOD 表

| LOD | 缩放 | 地形 | 矢量 | 聚落 | UI |
|---|---|---|---|---|---|
| 0 | 1–8× | 颜色+阴影（降采样） | 海岸线 + 主要河流 | 只画都城 | 罗盘+图例 |
| 1 | 8–30× | 颜色+阴影 | + 500 m 等高线（稀疏） | 都城+大城 | +图例 |
| 2 | 30–120× | 同上 | + 250 m 等高线 + 支流 | + 镇 | +道路 |
| 3 | 120–500× | 同上 | 全部 | + 邑/关 | + 名称 |

切换用淡入淡出（0.2 s），不做硬切。

## 5. 要删掉的东西

- `map_detail.gd`（屏幕细节层）、`terrain_contours.bin`、`terrain_lines.bin`；
- `_draw_vec_terrain`、`_draw_contours`（运行时节流采样）、分类边界绘制；
- 三套坐标变换里的两套。

保留：`main.gd` 的地图容器/滚动/缩放/快速旅行、`hydro.json`、聚落数据。
